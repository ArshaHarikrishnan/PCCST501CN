🧪 LAB 0

Introduction to Socket Programming

Linux TCP Socket Fundamentals

Learn the fundamentals of Linux Socket Programming, understand socket address structures, IP address conversion, network byte ordering, and prepare yourself for TCP Client–Server Programming.

Start Learning Download Lab

Learning Objectives

At the end of this lab, students will be able to

Understand Socket Programming

Learn how sockets enable communication between processes over a network.

Learn Socket Structures

Understand the sockaddr_in structure, its members, and their purpose.

Prepare for TCP Programming

Build the foundation needed for TCP Client and Server Programming.
