Theory

What is Socket Programming?

Socket Programming enables two applications running on different computers (or the same computer) to communicate over a network.

What is a Socket?

A socket is an endpoint of communication between two processes. Sockets allow applications to exchange data over TCP/IP or UDP.

Examples include:

  • Web Browsers
  • Web Servers
  • Email Clients
  • FTP Applications
  • Online Games
  • Video Conferencing

Client–Server Communication

The client sends requests. The server receives requests and sends responses.

Socket Address Structure

The socket address stores the IP address and Port Number. 


struct sockaddr_in

{

sin_family

sin_port

sin_addr

sin_zero

};
Field Description
sin_family Address Family (AF_INET)
sin_port TCP/UDP Port Number
sin_addr IPv4 Address
sin_zero Unused Padding Bytes

Hands-on Activity 1

Create Your First Socket Address Structure

socket_intro.c 

#include <stdio.h>

#include <string.h>

#include <arpa/inet.h>

int main()

{

struct sockaddr_in server;

memset(&server,0,sizeof(server));

server.sin_family=AF_INET;

server.sin_port=htons(8080);

inet_pton(AF_INET,

"127.0.0.1",

&server.sin_addr);

printf("Family : %d\n",

server.sin_family);

printf("Port : %d\n",

ntohs(server.sin_port));

return 0;

}
Compile 

gcc socket_intro.c -o socket_intro
Run 

./socket_intro
Expected Output 

Family : 2

Port : 8080

💡 Did You Know?

Almost every TCP or UDP program starts by creating a sockaddr_in structure.

⚠ Common Mistake

Students often forget to use htons() when assigning the port number.

Hands-on Activity 2

IP Address Conversion

Convert an IPv4 address between text format and binary format.

Program 

struct in_addr addr;

char ip[INET_ADDRSTRLEN];

inet_pton(AF_INET,
          "192.168.1.10",
          &addr);

inet_ntop(AF_INET,
          &addr,
          ip,
          sizeof(ip));

printf("%s", ip);
Expected Output 

192.168.1.10
Try This: Replace 192.168.1.10 with
  • 127.0.0.1
  • 8.8.8.8
  • 1.1.1.1
Observe the output.
Hands-on Activity 3

Network Byte Ordering

byteorder.c 

#include <stdio.h>

#include <arpa/inet.h>

int main()

{

unsigned short port=8080;

printf("Original : %u\n",port);

printf("Network : %u\n",

htons(port));

printf("Back : %u\n",

ntohs(htons(port)));

}
Expected Output 

Original : 8080

Network : xxxx

Back : 8080
