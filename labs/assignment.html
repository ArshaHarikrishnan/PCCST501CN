📌 About These Assignments

These assignments are designed to help students practice Socket Programming concepts before attempting the official laboratory experiments. Begin with the TCP Basics section, progress through UDP, String Processing, File Handling, and finally complete the Challenge Problems. Completing these exercises will strengthen your programming skills and prepare you for advanced client-server applications.
