🔎 Lab 2: HTTP Conversation Investigator

Reconstruct one browser–server conversation from captured packets.

Experiment02
ToolWireshark
FocusHTTP
EvidenceCase File

🎯 Mission

Capture one browser–server HTTP conversation and reconstruct what the client asked, what the server answered and how long the exchange took.

⚠️ Before You Capture

Modern websites normally use HTTPS. Use only the instructor-approved HTTP test resource and capture only your own permitted lab traffic.

🧪 Capture Workflow

  1. Close unnecessary browser tabs.
  2. Open Wireshark and select the active interface.
  3. Start capture and open the approved HTTP test page once.
  4. Stop capture.
Apply the display filter
http
Inspect the request

Record endpoint addresses, method, host, requested resource, HTTP version, language, encoding and user-agent fields when present.

Inspect the response

Record status code, reason phrase, content length and last-modified value when present.

Measure the exchange

Response delay = response timestamp − request timestamp.

🏁 Student Challenge

Tell the packet story in six lines: client, server, requested resource, browser preferences, server reply and measured delay.

❓ Viva

  1. Why are addresses reversed in the response?
  2. Method vs status code?
  3. Why can some headers be absent?
  4. Why does http not reveal normal HTTPS content?
  5. Which header identifies client software?
