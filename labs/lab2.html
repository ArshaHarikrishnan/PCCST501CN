🧪 Experiment 2

HTTP Packet Analysis using Wireshark

Wireshark Based Experiment

Experiment

02

Duration

3 Hours

Difficulty

Beginner

Category

Wireshark

🎯 Aim

To capture and analyze HTTP request and response packets using Wireshark and understand the working of the HTTP protocol.

📚 Learning Outcomes

  • Capture HTTP packets.
  • Analyze HTTP GET requests.
  • Identify HTTP response packets.
  • Interpret HTTP headers.
  • Measure response time.

💻 Software Required

  • Wireshark
  • Google Chrome / Firefox
  • Internet Connection

🔍 Wireshark Filter

http

📋 Procedure

  1. Open Wireshark.
  2. Start packet capture.
  3. Open a web browser.
  4. Visit a HTTP website.
  5. Stop packet capture.
  6. Apply the filter http.
  7. Observe the GET request and Response packet.
  8. Answer the analysis questions.

📝 Analysis Questions

  1. Find the Source IP Address.
  2. Find the Destination IP Address.
  3. Identify the HTTP GET request.
  4. Find the requested URL.
  5. Find the User-Agent.
  6. Find the HTTP Status Code.
  7. Find the Content-Length.
  8. Find the Last Modified field.
  9. Calculate the response time.

❓ Viva Questions

  1. What is Wireshark?
  2. What is HTTP?
  3. Difference between HTTP and HTTPS?
  4. What is GET Request?
  5. What is HTTP Status Code?

📝 Assignment

  • Capture HTTP packets.
  • Identify GET request.
  • Find Status Code.
  • Take screenshots.
  • Upload the report to your GitHub repository.
