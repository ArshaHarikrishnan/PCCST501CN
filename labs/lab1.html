🕵️ Lab 1: Linux Network Detective

Investigate network identity, connectivity, routes, services, performance and live traffic using the complete Linux networking command set in the syllabus.

🎯 Aim

To familiarize students with ifconfig, ifplugstatus, iftop, ping, ip, traceroute, mtr, netstat, whois, nmap, nmcli, speedtest-cli, bmon, nslookup and tcpdump, and interpret the network information produced by each tool.

⚙️ Before You Begin

Some tools may need installation on Ubuntu/Debian:

sudo apt update sudo apt install net-tools ifplugd iftop traceroute mtr-tiny whois nmap network-manager speedtest-cli bmon dnsutils tcpdump

Use nmap and tcpdump only on systems and networks for which you have permission.

🚀 Investigation Route

1. Legacy Interface View

Command: ifconfig

ifconfig ifconfig -a

Task: Find interface, IPv4 address, netmask, MAC address, RX and TX statistics.

2. Physical Link Check

Command: ifplugstatus

ifplugstatus ifplugstatus <interface>

Task: Check whether a wired interface reports a connected physical link.

3. Modern IP Investigation

Command: ip

ip -brief address ip link show ip route

Task: Find interface state, IP/prefix, MAC address, default route and gateway.

4. NetworkManager Status

Command: nmcli

nmcli device status nmcli connection show --active

Task: Find device type, state and active network profile.

5. Three-Stage Reachability Test

Command: ping

ping -c 4 <default-gateway> ping -c 4 8.8.8.8 ping -c 4 example.com

Task: Compare local reachability, Internet reachability and DNS-based reachability.

6. Route Investigator

Command: traceroute

traceroute example.com

Task: Record visible intermediate hops and missing replies.

7. Continuous Path Health

Command: mtr

mtr -r -c 10 example.com

Task: Observe repeated hop-by-hop loss and latency statistics.

8. Connection Inspector

Command: netstat

netstat -tuln netstat -rn

Task: Find listening TCP/UDP ports and the routing table.

9. Domain Registration Detective

Command: whois

whois example.com

Task: Observe publicly available registrar and registration information.

10. DNS Investigator

Command: nslookup

nslookup example.com

Task: Find the DNS server used and the returned IP address.

11. Approved Host Scan

Command: nmap

nmap localhost nmap -sV <instructor-approved-target>

Task: Find open ports and detected services only on authorized targets.

12. Internet Performance Test

Command: speedtest-cli

speedtest-cli

Task: Record latency, download speed and upload speed.

13. Live Bandwidth Conversation

Command: iftop

sudo iftop -i <interface>

Task: Observe endpoint pairs exchanging traffic and approximate rates.

14. Interface Bandwidth Monitor

Command: bmon

bmon

Task: Observe receive and transmit activity over time.

15. Packet Evidence Collector

Command: tcpdump

sudo tcpdump -D sudo tcpdump -i <interface> -c 10 sudo tcpdump -i <interface> icmp -c 5

Task: Observe timestamps, endpoints and protocol information on permitted traffic.

🏁 Student Challenge

Network Health Verdict

Classify the connection as Healthy, Partially Reachable, DNS Problem, High Latency, or Interface/Link Problem.

Support the verdict using at least five observations from five different commands. Do not simply paste terminal output.

❓ Viva Questions

  1. How do ifconfig and ip differ?
  2. What does ifplugstatus check?
  3. Why can ping to an IP succeed while ping to a domain fails?
  4. How are traceroute and mtr different?
  5. What can netstat show?
  6. How do whois and nslookup differ?
  7. Why must nmap be restricted to authorized targets?
  8. How do iftop and bmon differ?
  9. What do download and upload speeds represent?
  10. What information can tcpdump reveal?
