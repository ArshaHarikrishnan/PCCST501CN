Experiment 1

Linux Networking Commands

Warm-up Experiment

Aim

To familiarize students with Linux networking commands used for network configuration, troubleshooting and monitoring.

Learning Outcomes

  • Configure network interfaces.
  • Test connectivity.
  • Perform DNS lookup.
  • Monitor network traffic.

Commands Covered

ifconfig, ip, ping, traceroute, mtr, iftop, netstat, whois, nmap, nmcli, speedtest-cli, bmon, nslookup, tcpdump

Sample Commands

Display Interfaces
ifconfig
IP Address
ip addr
Connectivity Test
ping 8.8.8.8
Trace Route
traceroute google.com
DNS Lookup
nslookup google.com

Procedure

  1. Open Ubuntu Terminal.
  2. Execute each command.
  3. Observe the output.
  4. Capture screenshots.
  5. Record observations.

Viva Questions

  1. What is ifconfig?
  2. Difference between ifconfig and ip?
  3. What is ping?
  4. What is traceroute?
  5. What is nslookup?

Assignment

  • Find IP Address.
  • Find MAC Address.
  • Find DNS Server.
  • Upload screenshots to GitHub.
