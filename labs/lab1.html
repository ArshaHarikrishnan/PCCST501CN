🕵️ Lab 1: Linux Network Detective

Build a network profile of your own Linux system using evidence, not copied output.

Experiment01
ModeIndividual
LevelFoundation
EvidenceNetwork Profile

🎯 Mission

Investigate the network identity and connectivity of your Linux machine. Create an evidence-based profile containing interface details, IP configuration, gateway, DNS resolution, path information and active connections.

🧠 Questions to Discover

  • Which interface carries your traffic?
  • What are your IPv4 address, prefix, MAC address and default gateway?
  • Can you reach a local gateway, a public IP address and a domain name?
  • Which intermediate hops are visible?
  • Which TCP and UDP endpoints are active?

🚀 Investigation Route

1. Identify the Machine
hostnamectl ip -brief address ip link show

Record the active interface, IPv4 address, prefix and MAC address.

2. Find the Way Out
ip route

Identify the default route and default gateway.

3. Test Connectivity in Three Stages
ping -c 4 <default-gateway> ping -c 4 8.8.8.8 ping -c 4 example.com

Compare packet loss and average round-trip time. Explain what each test proves.

4. Follow the Packet Path
traceroute example.com mtr -r -c 10 example.com

Record the number of visible hops. Asterisks may appear when an intermediate device does not reply.

5. Ask DNS
nslookup example.com

Identify the DNS server and returned IP address.

6. Observe Local Network Activity
ss -tuln nmcli device status

Observe listening TCP/UDP endpoints and the state of network devices.

7. Optional Live Observation
sudo iftop -i <interface> sudo tcpdump -i <interface> -c 10

Capture only traffic on networks and systems for which you have permission.

🏁 Student Challenge

Network Health Verdict: Classify your connection as:

  • Healthy
  • Partially Reachable
  • DNS Problem
  • High Latency

Support your verdict using at least three observations collected during the experiment.

❓ Viva Questions

  1. Why can ping to an IP address succeed while ping to a domain name fails?
  2. Why is the ip command preferred over ifconfig on modern Linux systems?
  3. What does a default gateway do?
  4. Why can traceroute display * * * for some intermediate hops?
  5. What is the difference between a listening socket and an established connection?
